# BASO AI Builder (ستۆدیۆی فریلانسەر — تایبەت بە باسۆ)

ئەپلیکەیشنێکی تایبەت و کەسی بۆ **باسۆ (BASO)** بە هەمان دیزاین، ڕەنگ، و پێکهاتەی وێنە هاوپێچکراوەکە، بۆ دروستکردن و دیزاینکردنی وێبسایت، وێب ئەپ، و ئەپلیکەیشنی مۆبایل بە زیرەکی دەستکرد (Gemini AI)، پیشاندانی زیندوو (Live Preview)، پشکنەری کۆد و فایلەکان، و هەناردەکردنی فایلی `ZIP` — بەبێ Firebase و ئامادەکراو بۆ دروستکردنی ڕاستەوخۆی **APK** لە ڕێگەی **GitHub Actions**.

---

## بڕیارە پشتڕاستکراوەکان و پێداچوونەوەی بەکارهێنەر (User Review & Critical Decisions)

> [!IMPORTANT]
> **تایبەتمەندییە جێگیرکراوەکان بەپێی داواکاری و وێنەکەی باسۆ:**
> - **ئەپێکی تەواو تایبەت بە باسۆ (Personal Studio for BASO):** ئەپەکە بە ناوی **BASO — ستۆدیۆی فریلانسەر** و پڕۆفایلی کەسیی **«باسۆ»** لە سەرەوەی شاشەی ماڵەوە دیزاین دەکرێت، تەنها بۆ بەکارهێنانی خۆت و بەبێ هیچ سیستەمێکی چوونەژوورەوەی دەرەکی.
> - **دیزاین و ڕەنگی ١٠٠٪ هاوشێوەی وێنەکە:**
>   - پاشبنەمای تاریکی قووڵ (`#060D14` و `#0A1622`)
>   - ڕەنگی زەردی زێڕین (`#F5C518` / `#FACC15`) بۆ دوگمە سەرەکییەکان (`دەست پێ بکە`، `بەرهەمی نوێ دروست بکە`، `دابەزێنە`، و ناوی `باسۆ`)
>   - ڕەنگی شینی فیرۆزەیی درەوشاوە (`#00E5CC` / `#00D4FF`) بۆ چوارچێوەی کارتەکان، ئایکۆنەکان، تابی چالاک، و دوگمەی `پەیوەندی پڕۆژە دروست بکە ✨`
>   - لۆگۆی سێ دووری (3D Isometric)ـی پیتی **B** بە ڕەنگی زەرد و فیرۆزەیی.
> - **بێ Firebase و ئامادە بۆ GitHub Actions APK:** پاشەکەوتکردنی هەموو پڕۆژەکان لەسەر ئامێرەکە بە **Room SQLite** و دانانی فایلی `.github/workflows/build-apk.yml` بۆ وەرگرتنی ڕاستەوخۆی APK لە GitHub.

## ١. تێڕوانینی گشتی و بیرۆکەی سەرەکی (Overview & Core Concept)

- **ئەپەکە چی دەکات (What It Does):**
  ستۆدیۆیەکی کەسیی زیرەکی دەستکردە (`BASO AI Builder`) کە ڕێگەت پێدەدات بە کوردی یان ئینگلیزی بیرۆکەی پڕۆژەکەت بنووسیت و پلاتفۆرمەکەی هەڵبژێریت (`Android`، `Web`، یان `Web App`). زیرەکی دەستکرد کۆدی تەواوی پڕۆژەکە و پێکهاتەی فایلەکانی دروست دەکات، لە بەشی **پێشینە (Preview)** بە زیندوویی پیشانی دەدات، لە بەشی **کۆد (Code)** پێکهاتەی فۆڵدەر و فایلەکان دەخاتە ڕوو، و لە بەشی **دروستکردنی پڕۆژە** دەیکاتە فایلی ڕاستەقینەی `.zip` ئامادە بۆ دابەزاندن و بەکارهێنان.
- **زمانەکان (Languages):** زمانی سەرەکی کوردی (سۆرانی - RTL) هەروەک ناو وێنەکە، لەگەڵ دوگمەی گۆڕینی خێرا بۆ ئینگلیزی (LTR) لە بەشی ڕێکخستن و سەرەوەی ستۆدیۆکە.

## ٢. هەشت شاشە سەرەکییەکە و دیزاینی بینراو (The 8 Core Screens from Reference Image)

هەموو شاشەکان بە وردی لەسەر نەخشەی وێنەکەت دروست دەکرێن:

1. **شاشەی دەستپێک (Splash / Welcome Screen — `BASO ستۆدیۆی فریلانسەر`):**
   - لۆگۆی سێ دووری درەوشاوەی **B** بە ڕەنگی زەرد و فیرۆزەیی.
   - ناونیشانی گەورەی **BASO** و ژێرنووسی زەردی **ستۆدیۆی فریلانسەر**.
   - سێ تاگی درەوشاوە: `✦ دیزاین ✦` | `✦ وێبسایت ✦` | `✦ ئەپ ✦`.
   - دروشمی `هێزی خەلاقیت بە دیجیتاڵ دەکات` و دوگمەی زەردی `دەست پێ بکە ←`.
2. **شاشەی سەرەکی ماڵەوە (Home Dashboard — `ماڵەوە`):**
   - سەرپەڕە: دوگمەی مێنوو لەگەڵ ناوی **`باسۆ`** و وێنەی پڕۆفایلی تایبەت بە خۆت.
   - پێشوازی: `سڵاو، 👋 بەخێربێیت بۆ BASO`.
   - کارتی بانەری سەرەکی: `دروستکردنی ئەپ و وێبسایت بە شێوەیەکی ئاسان و خێرایی` لەگەڵ دوگمەی زەردی `بەرهەمی نوێ دروست بکە` و گرافیکی مۆبایل و لاپتۆپ.
   - بەشی **`بەشەکان`**: دوو کارتی سەرەکی بە چوارچێوەی فیرۆزەیی (`Web Builder - وێبسایت و وێب ئەپ` و `App Builder - ئەپلیکەیشن مۆبایل`).
   - بەشی **`پڕۆژەکانت`** لەگەڵ دوگمەی `بینین هەموو` و لیستی پڕۆژەکان.
   - شریتی خوارەوە (Bottom Navigation): `ماڵەوە` | `پڕۆژەکان` | `ئامێرەکان` | `ڕێکخستن`.
3. **شاشەی هەڵبژاردنی جۆری پڕۆژە (`دروستکردنی نوێ — هەڵبژاردنی جۆری پڕۆژەکەت`):**
   - کارتی یەکەم: **ئەپلیکەیشن مۆبایل** (`Android (Kotlin)`، `Material 3 UI`، `APK / Code Export`).
   - کارتی دووەم: **وێبسایت / وێب ئەپ** (`HTML / CSS / JS`، `Responsive Design`، `ZIP Export`).
   - سندوقی تێبینی زەرد لە خوارەوە: `💡 دەتوانیت لەگەڵ AI یەکەم پڕۆژەکەت دروست بکەیت.`
4. **شاشەی ستۆدیۆی زیرەکی دەستکرد (`BASO AI Builder — پڕۆمپت`):**
   - چوار تابی سەرەکی لە سەرەوە: `پڕۆمپت` | `پێشینە` | `کۆد` | `فایلەکان`.
   - خانەی نووسینی پڕۆمپت + هەڵبژاردنی پلاتفۆرم (`Android` | `Web` | `Web App`) + ڕێکخستنی شێوازی دیزاین و مۆدێلی AI (هاوشێوەی Google AI Studio).
   - دوگمەی درەوشاوەی فیرۆزەیی لە خوارەوە: `✨ پەیوەندی پڕۆژە دروست بکە` (لەگەڵ توانای ناردنی داواکاری زیاتر بۆ دەستکاریکردنی پڕۆژەکە).
5. **شاشەی پێشینەی زیندوو (`پێشینە — Live Preview`):**
   - سویچی سەرەوە: `Android` | `Web` | `Web App`.
   - چوارچێوەی وێبگەڕ و ئامێر بە شریتی ناونیشانی `https://preview.baso.app` و پیشاندانی زیندوو و کارلێککەری پڕۆژەکە لە ناو `WebView`، لەگەڵ ئامرازی دەستکاریکردنی ڕاستەوخۆی ڕەنگ و دیزاین.
   - شریتی خوارەوە: ٣ دوگمەی گۆڕینی قەبارەی ئامێر (تەبلێت / مۆبایل / دێسکتۆپ) + دوگمەی `👁 پیشینەی ڕاستەقینە` بۆ کردنەوەی بە پڕشاشە (Full Screen).
6. **شاشەی کۆد و درەختی فایلەکان (`کۆد — Code & File Tree`):**
   - تابی سەرەوە: `Android` | `Web` | `Files`.
   - لای چەپ: درەختی فۆڵدەر و فایلەکان (`web-app/src/components/Header.jsx`, `pages/Home.jsx`, `assets/style.css`, `index.html`, `package.json` یان فایلەکانی Kotlin بۆ Android).
   - لای ڕاست: پیشاندەری کۆد بە ڕەنگکردنی ڕستەکان (Syntax Highlighting) و ژمارەی دێڕەکان.
   - دوو دوگمە لە خوارەوە: `کۆپی کۆد` و `هاوبەشکردن`.
7. **شاشەی دروستکردن و دابەزاندنی فایلی ZIP (`دروستکردنی پڕۆژە`):**
   - هەنگاوە تەواوکراوەکان بە نیشانەی سەوز:
     - `پڕۆژە دروست کرا` ✅
     - `کۆد و فایلەکان ئامادەیە` ✅
     - `بەستەبەندی (ZIP) دروست کرا` ✅
   - کارتی سەرکەوتن: `پڕۆژەکەت بە سەرکەوتوویی دروست کرا! دەتوانیت فایلەکە دابەزێنیت و بەکاریبهێنیت.`
   - کارتی فایلی ئامادەکراو (`my-project.zip` بە قەبارەی ڕاستەقینە) + دوگمەی زەردی `⬇ دابەزێنە` (کە فایلی `.zip`ـی ڕاستەقینە پاشەکەوت و هاوبەش دەکات) + دوگمەی `📁 بینینی فایلەکان`.
8. **شاشەی لیستی پڕۆژەکان و ئامێرەکان (`پڕۆژەکان` & `ئامێرەکان`):**
   - گەڕان بەدوای پڕۆژەکاندا، دوگمەی زەردی `+` بۆ پڕۆژەی نوێ، و فلتەرکردن بەپێی (`هەموو` | `Android` | `Web` | `Web App`).
   - لە تابی **ئامێرەکان (AI Studio Tools)**: ئامرازی تایبەت بە دیزاینی ڕەنگ و فۆنت، چاکسازیکردنی کۆد، و گۆڕینی بیرۆکە بۆ دیزاین.

### مۆدێلی داتا لە Room Database (`BasoProjectEntity`)
- `id`: ناسنامەی پڕۆژە (`PrimaryKey`)
- `title`: ناوی پڕۆژە (بۆ نموونە `My Shop`, `Food Delivery`, `Portfolio Website`)
- `platform`: جۆری پلاتفۆرم (`Android`, `Web`, `Web App`)
- `prompt`: دەقی داواکارییەکەی باسۆ
- `previewHtml`: کۆدی تەواو و کارلێککەری HTML/CSS/JS بۆ بەشی **پێشینە (Live Preview)**
- `filesJson`: لیستی هەموو فایل و فۆڵدەرەکانی پڕۆژەکە (`index.html`, `src/pages/Home.jsx`, `MainActivity.kt`, هتد) بۆ پیشاندان لە درەختی فایلەکان و دروستکردنی فایلی `ZIP`
- `designConfigJson`: ڕێکخستنەکانی ڕەنگ و شێوازی دیزاین
- `createdAt` / `updatedAt`: کاتی دروستکردن و نوێکردنەوە
